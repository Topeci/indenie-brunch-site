# Indénié Brunch — Site

Site vitrine Next.js pour l'Indénié Brunch (Abengourou, Côte d'Ivoire).

## Développement local

```bash
npm install
npm run dev
```

## Déploiement

Ce projet est prêt pour Netlify : connecter le dépôt GitHub, Netlify détecte
Next.js automatiquement (commande de build `next build`).

## À faire

- Remplacer les prix `[PRIX]` dans la section Billetterie
- Ajouter l'email / téléphone de contact dans le footer
- Écrire les vrais articles dans la section Actus
- Brancher le paiement Wave sur les boutons "Réserver"
